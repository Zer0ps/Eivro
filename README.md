# Eivro

Eivro («Эйвро») — приложение для Linux, которое позволяет подключаться к VPN
и прокси-серверам, управлять подписками и выбирать, какой трафик направлять
через подключение.

Для работы нужна ссылка на сервер или подписка от провайдера.
Собственных VPN-серверов Eivro не предоставляет.

## Возможности

- Добавление отдельных серверов и подписок, ручное и автоматическое обновление.
- Подключение всей системы через TUN или отдельных приложений через прокси.
- Правила для доменов, IP-адресов и приложений, отдельные профили маршрутизации.
- Сетевые выходы с выбранным интерфейсом и DNS, например для рабочего VPN.
- Работа в трее, светлая и тёмная темы, выбор цветов интерфейса.

## Установка

Для Linux x86_64 доступны пакеты RPM и DEB. Выполняйте команду из каталога
с пакетом.

Fedora:

```sh
sudo dnf install ./eivro-1.2.2-1.x86_64.rpm
```

Debian:

```sh
sudo apt install ./eivro_1.2.2_amd64.deb
```

После установки откройте Eivro из меню приложений.
Перед обновлением отключите соединение и завершите приложение через трей.
Для перехода со старого названия Velum есть [инструкция](docs/UPGRADE.md).

AppImage и переносимый архив подходят для работы с прокси.
Для TUN нужен установленный RPM или DEB с системным помощником.

## Начало работы

1. Откройте «Подписки» → «Добавить» и вставьте ссылку на сервер или подписку.
   Также можно импортировать файл.
2. На странице «Соединение» выберите сервер и режим подключения.
3. Нажмите «Подключиться».

| Режим | Как работает |
| --- | --- |
| TUN | Направляет трафик системы через Eivro с учётом правил. Требует разрешения администратора. |
| Прокси | Включает системный прокси GNOME для приложений, которые его учитывают. |
| Локально | Предоставляет HTTP/SOCKS5-прокси, адрес которого нужно указать в приложении. |

Исключения настраиваются на странице «Маршруты». Например, можно направить
рабочие сайты через корпоративный VPN, а остальные — через выбранный сервер.
При смене сервера, режима или применении правил соединение переподключается.

В KDE используйте TUN или настройте локальный прокси в нужном приложении.
Поддержка трея зависит от окружения рабочего стола. Защита при обрыве TUN
(kill switch) пока экспериментальная и выключена по умолчанию.

No logs.
