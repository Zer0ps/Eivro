# Eivro 1.3.0 — macOS preview

Добавлен предварительный порт для macOS 13 и новее на Intel и Apple Silicon.

- Общие интерфейс, подписки и профили маршрутизации с Linux.
- Системное меню macOS, значок в строке меню, автозапуск и сочетание ⌘B.
- Отдельный помощник для подключения, системного прокси и TUN.
- Сборки PKG/DMG и проверки для обеих архитектур в GitHub Actions.

Порт требует проверки на Mac перед стабильным выпуском. Сборки ad-hoc подписаны;
Developer ID и нотариализация не настроены. Экспериментальный kill switch
на macOS недоступен. Подробности установки и ограничений — в `docs/MACOS.md`.

Для Linux перед обновлением отключите VPN и завершите приложение через трей.

```sh
sudo dnf install ./eivro-1.3.0-1.x86_64.rpm
```

```sh
sudo apt install ./eivro_1.3.0_amd64.deb
```
