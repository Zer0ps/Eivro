# Velum 1.0.0 Stable

Первый стабильный выпуск Linux-клиента для x86_64.

Обновлён интерфейс в рамках той же версии 1.0.0: равные карточки и общая
линия действий, акцентные кнопки правил, одинаковые цветовые образцы,
компактный редактор с постоянно доступными кнопками подтверждения.
Для переустановки RPM поверх прежней 1.0.0 используйте `sudo dnf reinstall ./velum-1.0.0-1.x86_64.rpm`.

- Исправлено отключение системного прокси GNOME после изменения исключений.
  Новые исключения сохраняются, адреса остановленного Velum восстанавливаются.
- Отмена подключения и таймаут загрузки подписки больше не ждут зависший
  системный DNS. Резолвер запускается только на время запроса, без журналов.
- Официальные Xray 26.10.21 и sing-box 1.14.4; обновлённые rustls/WebPKI/Tokio.
- Подписки, трей, маршрутизация и настройки предыдущих alpha совместимы.
- Исправлены зависимости DEB для Debian 13: polkitd и pkexec.
- DEB содержит явные родительские каталоги для установки на чистую систему.
- CI проверяет код, DEB/RPM и установку на Debian 13/Fedora 44.

Перед обновлением отключите VPN и завершите Velum. Затем установите DEB через
`sudo apt install ./velum_1.0.0_amd64.deb` или RPM через
`sudo dnf install ./velum-1.0.0-1.x86_64.rpm` и снова запустите Velum.

NOLOGS относится к приложению и ядрам клиента; политика DNS/VPN-провайдера
определяется самим провайдером. Kill switch остаётся экспериментальным.
IPv6 и arm64 не входят в проверенную матрицу этого выпуска.
В зависимостях официального sing-box остаются известные advisory; подробности
и границы проверок — docs/VERIFICATION.md. Пакеты не подписаны GPG.
