# Eivro 1.2.2

Проект Velum переименован в Eivro. Пакет заменяет прежнюю установку;
настройки переносятся при первом запуске. Инструкция перехода и отката
находится в `docs/UPGRADE.md` в исходниках.

## Изменения с 1.0.0

- Обновлён интерфейс: отдельные страницы соединения, подписок, маршрутов
  и настроек; боковое меню и каталог серверов можно скрывать.
- Добавлены сетевые выходы с выбранным интерфейсом и DNS для рабочего VPN
  и других подключений.
- Правила можно выделять кликом по строке, менять направление в списке
  и редактировать группой. Изменения применяются одной кнопкой.
- Добавлены палитры, собственный цвет акцента и короткие эффекты подключения
  и отключения. «Уменьшить движение» отключает анимации.

## Обновление

Перед установкой отключите VPN и завершите приложение через трей.

```sh
# Fedora
sudo dnf install ./eivro-1.2.2-1.x86_64.rpm

# Debian
sudo apt install ./eivro_1.2.2_amd64.deb
```

Защита при обрыве TUN остаётся экспериментальной и несовместима с внешними
сетевыми выходами. Режим системного прокси поддерживает GNOME; в других
окружениях доступны TUN и локальный прокси.

Проверки описаны в `docs/VERIFICATION.md`, работа с данными — в `PRIVACY.md`.
