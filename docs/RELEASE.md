# Eivro 1.5.1

Каталог серверов плавно открывается и закрывается. Повторный выбор текущего сервера сохраняет соединение. Переключение сервера, остановка VPN и отмена запроса прав теперь имеют отдельные состояния.

На Linux, macOS и Windows раздел «Диагностика» помечен BETA. В «Информации» доступны версия приложения, результат последней проверки и просмотр обезличенного отчёта.

Пакеты Linux включают RPM и DEB. Для macOS 26 доступны PKG и DMG для Apple Silicon и Intel. Для Windows x64 доступны установщик EXE и переносимый ZIP. Режим TUN требует системного помощника из установочного пакета.
