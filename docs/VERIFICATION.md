# Velum 1.0.0 Stable — проверка

27 октября 2026. Cargo, RPM и DEB: 1.0.0.
Fedora 44 x86_64; Rust 1.98.1, egui/eframe 0.33.3.
Официальные sing-box 1.14.4 и Xray 26.10.21 (1b1647c).

## Исправления после ревью

- GNOME proxy: изменение ignore-hosts не мешает восстановить адреса Velum.
  Новые исключения сохраняются; настройки другого прокси-клиента не
  перезаписываются. Ошибка записи оставляет recovery snapshot для повторной
  попытки. Смена владельца завершает старую аренду настроек.
- Системный DNS: getaddrinfo вынесен в короткоживущий процесс с ограниченным
  stdin/stdout, без имён в argv и без журналов. Отмена завершает и reap-ит
  процесс. Таймаут DNS подключения — 10 секунд; HTTPS-подписка и все её
  перенаправления разделяют общий deadline 20 секунд, включая DNS.
- Версии UI/CLI и пакетов согласованы: 1.0.0. Упаковка читает Cargo.toml,
  проверяет версии GUI, помощника и ядер, создаёт архив исходников по whitelist.
- GitHub Actions: pinned actions, read-only проверки, write только у release job,
  DEB/RPM + установка в контейнеры, SHA256SUMS, черновик релиза по тегу.

Сохранены TLS-исправления alpha.7: rustls 0.23.46, rustls-webpki 0.103.16,
webpki-roots 1.0.10 и Tokio 1.53.3. Настройки alpha.2–alpha.7 совместимы.
Новых опросов, фоновых пингов или журналов приложение не ведёт.

## Проверка интерфейса той же версии 1.0.0

Снимки сделаны на отдельном Xvfb с программным Mesa renderer и синтетическими
настройками, без подключения VPN. Проверены светлая/тёмная темы, 14 правил,
настройки, редактор адресов и приложений, размеры 960×760 и 820×640.
Карточки и основные действия выравниваются по измеренному содержимому;
список и тело редактора прокручиваются отдельно от кнопок подтверждения.
В низком окне уменьшаются индикатор подключения и число правил в превью.
QA-сборка не включается в готовые пакеты. Версия и сетевые настройки сохранены.

## Автоматические проверки

Команды воспроизведения:

```sh
./scripts/check.sh
./scripts/build.sh
python3 scripts/verify-packages.py
CONTAINER_ENGINE=podman scripts/smoke-container.sh debian
CONTAINER_ENGINE=podman scripts/smoke-container.sh fedora
```

Регрессии включают настоящий GNOME/dconf в приватном D-Bus и искусственно
зависший DNS worker без изменения DNS хоста. Проверяются отмена Session,
срок всей загрузки подписки и отсутствие живых дочерних процессов после отмены.
Также проверяются Reality/Vision и XHTTP, подписки, маршруты, NOLOGS,
жизненный цикл помощника и kill switch в отдельном network namespace.

Конкретные результаты локального выпуска находятся в dist/Velum-1.0.0-package-checks.json
и сопроводительном отчёте. Workflow проверяется actionlint локально; первый
реальный запуск GitHub Actions возможен только после загрузки репозитория.
Контейнерная установка не подтверждает GUI/TUN на каждом дистрибутиве.

## Сравнение официальных ядер в Fedora ВМ

Сравнивались sing-box 1.14.2, 1.14.4, 1.15.0-alpha.13 и Xray 26.9.30/26.10.21.
Для личного TCP/Reality профиля использовался явный Firefox fingerprint.
Все шесть сочетаний sing-box + Xray передавали HTTPS и DNS через DoH.
Из первых 18 полных HTTPS-загрузок 17 завершились; один ответ YouTube с HTTP
200 достиг ограничения чтения 10 секунд. Три повторные загрузки через выбранную
пару завершились за 1,49–1,86 секунды. Нативный sing-box не подключился к этому
Reality-серверу ни на одной из трёх версий, поэтому Xray bridge сохраняется.

Пара sing-box 1.14.4 + Xray 26.10.21 в отдельном временном TUN прошла IPv4
HTTPS без proxy, DNS через 172.31.250.2 и UDP STUN. После остановки интерфейс
исчез, ip rules и внешний маршрут восстановились; /etc/resolv.conf не менялся.
Проверка выполнялась лабораторными процессами, а не установкой нового RPM.
Тесты нового пакета и контрольные суммы отражаются в выпускных артефактах.
Короткий idle-замер не является сравнением энергопотребления.

## ИБ и ограничения

Версионная проверка Cargo.lock в OSV после обновления не должна содержать
RUSTSEC-2026-0346..0349, RUSTSEC-2026-0381, RUSTSEC-2026-0382 или
RUSTSEC-2026-0386. Другие предупреждения рассматриваются по применимости:
ZIP-файлы читаются ограниченно в памяти, extract не вызывается; maintenance
notices для ttf-parser/zvariant не означают продемонстрированную эксплуатацию.

Официальный sing-box 1.14.4 сохраняет зависимости с advisory, в том числе
x/net HTTP/2 Transport в DoH. Это не объявляется полностью чистым сканированием.
Режимы gRPC-сервера, SSH и DHCP DNS в конфигурации Velum не включены.
Проверка версий зависимостей не заменяет анализ достижимости уязвимых символов.

IPv6, arm64, каждый дистрибутив, сетевой namespace, приложение и длительное
энергопотребление не проверялись. Kill switch остаётся экспериментальным.
Системный пакет на основном хосте в процессе сборки не заменяется; рабочий
VPN отключается пользователем перед ручной установкой нового RPM.

Файлы выпуска: Velum-1.0.0-SHA256SUMS,
Velum-1.0.0-package-checks.json и
Velum-1.0.0-VERIFICATION.md. Целевой ABI glibc 2.31;
фактические требуемые символы проверяются отдельно в пакетах.
