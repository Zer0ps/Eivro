# Eivro для macOS

Предварительный порт для macOS 13 и новее, Intel и Apple Silicon. Интерфейс,
подписки и правила общие с Linux. Нативные сборки и проверки выполняются
в GitHub Actions на macOS; запуск VPN и восстановление сетевых настроек
требуют отдельной проверки на Mac перед стабильным выпуском.

## Установка

Для каждой архитектуры собираются `.pkg` и `.dmg`. DMG содержит установщик.
Пакет устанавливает `Eivro.app` в `/Applications` и системный помощник.
Одного копирования приложения недостаточно для запуска подключения.

Текущая сборка подписывается ad-hoc. Developer ID и нотариализация не настроены;
macOS может блокировать её установку или запуск. Сборка предназначена для
проверки порта и не объявляется готовым стабильным выпуском.

## Работа

Доступны локальный HTTP/SOCKS5, системный прокси и TUN. Для системного прокси
и TUN macOS запрашивает права администратора. Разрешение относится к соединению
GUI с помощником и сохраняется до завершения приложения. Отмена запроса прав
завершает отдельный процесс авторизации; окно приложения не должно зависать.

Помощник принимает только ограниченные команды подключения. Он запускается
через socket activation launchd, ждёт события без периодического опроса и
завершается, когда закрыт последний клиент. Xray и обычный прокси работают
от имени пользователя; повышенные права остаются у TUN и записи системных настроек.

TUN использует `utun233`. DNS меняется только у основного сетевого сервиса;
DNS отдельных рабочих VPN сохраняется. Предыдущие значения DNS/прокси записываются
перед изменением в закрытый файл восстановления. При отключении или обрыве канала
GUI помощник останавливает ядра и восстанавливает только те значения, которые
ещё совпадают с применёнными Eivro. Изменения другого приложения сохраняются.
При аварии помощника launchd завершает его дочерние процессы, а восстановление
настроек выполняется при следующем старте помощника.

Экспериментальный kill switch пока доступен только в Linux. На macOS его нельзя
включить; запрос с включённой защитой отклоняется. Корректность совместной работы
с конкретным корпоративным VPN необходимо проверить отдельно.

## Данные

Настройки: `~/Library/Application Support/eivro/settings.json`, права `600`.
Ключи хранятся без шифрования. Абсолютный `XDG_CONFIG_HOME` поддерживается
для изолированных проверок. Трафик, DNS-запросы и подключения не журналируются.

Помощник хранит только снимок DNS/прокси в
`/Library/Application Support/EivroHelper/network-recovery.json`, доступный root.
Снимок удаляется после успешного восстановления. Перед запуском TUN имя сервера
разрешается через системный DNS; DNS bootstrap запущенного ядра использует
DoH Cloudflare через выбранный внешний интерфейс, чтобы избежать петли через TUN.

## Удаление

Отключите автозапуск, завершите Eivro, затем выполните:

```sh
sudo /Applications/Eivro.app/Contents/Resources/uninstall.sh
```

Скрипт восстанавливает сетевые настройки и удаляет приложение с помощником.
Пользовательские настройки и ключи сохраняются.

## Сборка

На macOS с Xcode Command Line Tools и Rust из `rust-toolchain.toml`:

```sh
./scripts/build-macos.sh
```

Официальные ядра загружаются с закреплёнными версиями и SHA-256. Сборка создаёт
приложение, PKG, DMG и контрольные суммы в `dist/`, но ничего не устанавливает.
Нативная интеграция находится в `native/macos/`, платформенная часть Rust —
в `src/platform/macos/`. Проверка Rust-target на Linux не проверяет компиляцию
Objective-C, линковку Apple frameworks или поведение сети macOS.
